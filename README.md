# Site Institucional — SPOT

Repositório acadêmico desenvolvido para o **site institucional do projeto SPOT — Sistema de Prevenção Operacional de Terminais**.

O site apresenta a proposta do projeto, seus objetivos e soluções, além de disponibilizar recursos para que o usuário realize seu **cadastro e login** e, após a autenticação, tenha acesso à **dashboard de monitoramento**.

## Objetivo

Este repositório tem como objetivo desenvolver o **site institucional e a aplicação web do projeto SPOT**, integrando as páginas da aplicação, o banco de dados e os diferentes componentes do sistema.

Por meio do site, o usuário poderá conhecer a proposta do SPOT e entender como a solução realiza o monitoramento da infraestrutura computacional. Após realizar o cadastro e o login, o usuário terá acesso à dashboard, onde poderá visualizar as informações e métricas dos componentes monitorados.

A aplicação busca centralizar essas informações em uma única plataforma, permitindo a visualização dos dados coletados e o acompanhamento do histórico dos componentes.

## Site Institucional

A parte institucional apresenta informações sobre:

*  Objetivo do projeto;
*  Solução proposta;
*  Contexto de aplicação;
*  Monitoramento dos componentes;
*  Acesso à plataforma.

O site funciona como o primeiro contato do usuário com o projeto, apresentando a proposta do SPOT antes do acesso à área de monitoramento.

##  Cadastro e Login

A aplicação também possui um sistema de autenticação, permitindo que o usuário:

*  Realize seu cadastro;
*  Faça login;
*  Tenha seus dados armazenados no banco de dados;
*  Acesse a dashboard após a autenticação.

## Dashboard

Após realizar o login, o usuário terá acesso à **dashboard de monitoramento**, responsável por apresentar as informações coletadas dos componentes do computador.

Entre as métricas acompanhadas pelo projeto estão:

*  CPU;
*  Memória RAM;
*  Disco;
*  Rede.

A documentação do projeto define que a dashboard deve utilizar os dados armazenados para exibir as métricas e permitir o acompanhamento do histórico dos componentes monitorados.

## Banco de Dados

O banco de dados é responsável pelo **armazenamento e gerenciamento das informações utilizadas pela aplicação**, permitindo que os dados sejam persistidos e posteriormente apresentados na dashboard.

A aplicação utiliza um **banco de dados relacional MySQL**, conforme definido nos requisitos do projeto.

## Projeto acadêmico

Este repositório faz parte do desenvolvimento acadêmico do **projeto SPOT**, tendo como objetivo colocar em prática conhecimentos de desenvolvimento web, integração entre sistemas, banco de dados e construção de aplicações multiplataforma.

A aplicação representa a parte **web e institucional do projeto**, conectando a apresentação da solução ao sistema de autenticação e à dashboard de monitoramento.
